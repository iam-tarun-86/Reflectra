# REFLECTRA — Project Context & Master System Architecture

## Project Summary
**REFLECTRA** is an Adaptive Multi-Agent Biometric Emotion Mirror.
It captures live webcam video, analyzes facial expressions at 5–10 Hz using DeepFace (RetinaFace), tracks emotional momentum using a 15-frame temporal rolling window, maps affect onto a 2D Russell Circumplex vector field (Valence vs Arousal), gates reactions via a deterministic Governor, and synthesizes empathetic observations via an LLM (Gemma 2B/4B / Qwen) with Web Speech & procedural Web Audio API audio synthesis.

## Multi-Agent Architecture (5-Agent Neural Pipeline)
```
[Webcam Stream] ➔ [Vision Agent (DeepFace 5Hz)]
                         ↓
               [Emotional State Agent (Rolling 15-Window)]
                         ↓
               [Context Memory Agent (Session History)]
                         ↓
               [Reaction Governor (Rule Gate, Cooldown 4s)]
                         ↓
               [LLM Response Agent (Gemma/Qwen or Heuristic Fallback)]
                         ↓
               [Living Emotion Orb & Web Audio/Speech Synthesis]
```

1. **Vision Agent (`agents/vision.py`)**: Captures video frames, extracts 7-class emotion probabilities (`happy`, `sad`, `surprise`, `angry`, `fear`, `disgust`, `neutral`), face bounding box `{x, y, w, h}`, and landmark confidence.
2. **Emotional State Agent (`agents/state.py`)**: 15-frame exponential rolling buffer that prevents single-frame blink flickers, calculating stability ($0\%\rightarrow 100\%$) and trend direction (`rising`, `falling`, `stable`).
3. **Context Memory Agent (`agents/context.py`)**: Maintains session duration, historical transitions, and dominant mood tracking (excluding synthetic debug events).
4. **Reaction Governor (`agents/governor.py`)**: Deterministic gating rule requiring sustained emotion shifts ($\ge 1.2\text{s}$), high confidence ($\ge 0.60$), and 4.0s minimum cooldown to prevent reaction spam.
5. **LLM Response Agent (`agents/llm.py`)**: Formulates contextual prompts referencing *facial-expression patterns* (not diagnosing internal feelings) with strict regex sanitization (`sanitize_llm_text`) to strip reasoning artifacts.
